# Phase 4 Chat Mechanics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Phase 4: a local transparent chat playground that exposes message formatting, tokenization, context assembly, sampling, streaming, tool verification, memory, failure cases, and preference/RLHF-style simulation.

**Architecture:** Extend the existing course/content/API/lab/web seams. Chat mechanics live in focused pure-Python modules under `llm_from_scratch.chat`, FastAPI exposes deterministic local chat endpoints, SQLite persists saved memory, and React renders a study-oriented chat playground with trace panels rather than a black-box chat surface.

**Tech Stack:** Python 3.13, pytest, FastAPI, Pydantic, SQLite, Vite, React, TypeScript, Vitest, React Testing Library, Playwright, deterministic local Python demos.

---

## Scope Boundary

This plan implements Phase 4 from `docs/superpowers/specs/2026-05-27-phase-4-chat-design.md`.

Included:

- Chat Product curriculum.
- Local chat trace engine.
- Chat demo API.
- Failure museum API.
- Preference/RLHF simulation API.
- Saved local memory API.
- React Chat Playground.
- Browser e2e flow.

Deferred:

- Paid or hosted model APIs.
- Internet retrieval.
- Arbitrary code execution.
- Production RAG.
- Production RLHF.
- Multi-user cloud memory.
