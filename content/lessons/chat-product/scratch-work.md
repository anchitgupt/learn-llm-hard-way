# Scratch Work

Some tasks need intermediate tokens. A short-answer constraint can force the model to answer before it has represented the steps.

Scratch-work mode shows that extra intermediate text can help decomposition. The local demo keeps this visible as a trace rather than hiding it.

## What To Inspect

- Short answer output.
- Scratch-work output.
- Intermediate reasoning tokens.
- Final answer.

## Checkpoint

Explain why intermediate tokens can help with multi-step tasks.
