# Tool Verification

Tool verification is useful when the task has an exact answer. Arithmetic is the simplest example.

A model-only answer can sound plausible. An allowlisted verifier computes the expression directly and returns a trace showing what was checked.

## What To Inspect

- User request.
- Model-only behavior.
- Tool trace.
- Verified result.

## Checkpoint

Explain why a calculator-style verifier is safer than model-only arithmetic.
